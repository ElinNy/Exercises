# C# Exercises  

Welcome to my coding journal! ✨  
This repository is where I collect all my **school exercises in .NET and C#** as I start my journey into backend development.  

I’m organizing my work with a **branching structure**:  
- **Modules** - one branch per school module.  
- **Categories** - sub-branches for exercises within that module.  

This way I can look back later and see how my skills have grown over time.

---

## Goals  
- Practice C# fundamentals.  
- Explore .NET features.  
- Build good habits with Git branching.  

---

## Structure  
- `main` - Overview & setup.  
- `module-*` - Branches for each school module.  
- `category-*` - Sub-branches for different exercises.  

---

👉 This repo is not a polished app, but a **collection of exercises** documenting my learning process.
